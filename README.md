# Warframe Tools Collection

Warframe 相关开源工具项目集合，以 git submodule 方式管理。

## 子项目

| 项目 | 说明 | 来源 |
|------|------|------|
| [warframe-public-export-plus](./warframe-public-export-plus/) | 物品数据、区域、挑战与本地化词典 | [calamity-inc/warframe-public-export-plus](https://github.com/calamity-inc/warframe-public-export-plus) |
| [riven-mirror](./riven-mirror/) | 裂罂分析器（Riven Mirror） | [pa001024/riven-mirror](https://github.com/pa001024/riven-mirror) |
| [warframe-api-server](./warframe-api-server/) | Warframe API 服务端（含国服节点名称映射） | [Dreamsunqing/warframe-api-server](https://github.com/Dreamsunqing/warframe-api-server) |

## 更新子模块

```bash
git submodule update --remote --merge
```
